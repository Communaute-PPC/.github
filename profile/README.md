# Projets communautaires de la PPC

L'[association pour la Pérennité Programmée Circulaire](https://www.perennite-programmee-circulaire.org/) (PPC) bénéficie d'une communauté 
de contributeurs actifs, actuellement centrée autour de groupes de travail (GT) ayant pour objectifs principaux de contribuer à l'évolution 
du référentiel PPC et de proposer toute iniative permettant à la PPC de devenir un modèle économique utilisé par des milliers d'entreprises.
